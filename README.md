# Bay-Beach Inn — Luxury Hospitality Landing Page

A stunning, production-ready single-file HTML landing page for Bay-Beach Inn, a bohemian coastal sanctuary resort in Virginia Beach.

## Features

✨ **Modern Design**
- Glassmorphic UI with backdrop blur effects
- Custom luxury color palette (Royal Blue, Warm Banana Cream, Soft Sand)
- Fully responsive (mobile → desktop)
- Smooth animations & transitions

🎨 **Components**
- Fixed navigation header with smooth scrolling
- Full-viewport hero section with gradient overlay
- Bento grid sanctuary features
- Curated suites showcase
- Contact & reservation section
- Footer

⚡ **Performance**
- Single HTML file (no build required)
- Tailwind CSS via CDN
- Lucide icons via CDN
- Zero JavaScript dependencies
- Instant deployment

## Quick Start

1. **Open locally:**
   ```bash
   open index.html
   ```

2. **Or deploy instantly to:**
   - [Netlify](#netlify)
   - [Vercel](#vercel)
   - [GitHub Pages](#github-pages)

## Deployment Options

### Netlify
1. Go to [netlify.com](https://netlify.com)
2. Sign up (free)
3. Drag & drop `index.html` into the upload area
4. **Done!** You get a live URL instantly

**Pro Tip:** Connect your GitHub repo for auto-deployments on every push.

### Vercel
1. Go to [vercel.com](https://vercel.com)
2. Sign in with GitHub
3. Import this repository
4. Click "Deploy"
5. **Live in ~1 minute** with automatic HTTPS

### GitHub Pages
1. Push this repo to GitHub as `bay-beach-inn`
2. Go to **Settings → Pages**
3. Select "Deploy from branch: main"
4. **Live at:** `username.github.io/bay-beach-inn`

## Customization

Edit `index.html` to update:

- **Brand:** Change "Bay-Beach Inn" text in header & footer
- **Colors:** Replace hex values:
  - `#1240A2` → Royal Blue
  - `#F3E6BB` → Warm Banana Cream
  - `#D2B48C` → Soft Sand
- **Content:** Update suite names, prices, descriptions
- **Contact:** Replace phone & email
